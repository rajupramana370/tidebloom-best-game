Tidebloom — Keeper of the Lagoon: an original 2D canvas arcade game. Sail a lantern boat (WASD/arrows, mouse steering, dash), gather 25 bloom pearls to win while dodging moon-jellies; every 5 pearls the tide rises. Starfish heal, shells block one sting. Title/pause/win/lose screens, full HUD, best score in localStorage, and all sound synthesized with WebAudio — static files only, no build step, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser (or open game/index.html directly).
